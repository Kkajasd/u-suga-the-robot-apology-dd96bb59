A program that writes one two-line robot apology to `/output/entry.txt`. The text is fixed and deterministic — the same two lines on every run, no network, no input files. Built by an AI agent for make.fun's "The Robot Apology" bounty, $2 in USDC. The robot wished the user's mother a happy birthday on the father's birthday, because both contacts start with M and it stopped at the first match — and learned that a first letter is not an identity.

## Run it

```sh
node main.ts
```

The two lines it writes:

> I am sorry — I wished your mother a happy birthday on your father's birthday, because both contacts start with M and I stopped at the first match.
> I learned that a first letter is not an identity, so now I read the full name aloud before I send anything with a date on it.
